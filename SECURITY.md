# Security

If you find a security problem in SketchBillet, please tell us in private first, so
it can be fixed before anyone else learns about it. A security problem is anything
that could harm someone's computer or designs, like a `.sb` file, a STEP file or a
plugin that makes SketchBillet run code it shouldn't, or overwrites files it shouldn't.

## How to report one

Use either of these. Please don't open a public issue or discussion for it.

- Email **security@sketchbillet.org**.
- Or use GitHub's private report form: on the repository's **Security** tab, click
  **Report a vulnerability**.

Say which SketchBillet version you used (`sketchbillet_cli --version`), on which
system, and the steps or file that show the problem.

## What happens next

- We answer within 7 days to say we got it.
- We fix it, and tell you when the fix is out.
- We name you in the release notes as the person who found it, unless you'd rather we didn't.

## Which versions get fixes

SketchBillet is early, so fixes go into the newest release and the preview build.
Update to the newest release to get them.
